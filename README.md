# Task 3 - Task Automation with Python

A small automation toolkit implementing two CodeAlpha-specified automation ideas.

## Automations
1. Move all `.jpg` files from one folder to another.
2. Extract email addresses from a `.txt` file and save them to another file.

## Requirements
- Python 3.x
- No external libraries

## Run
```bash
python main.py
```

## Safety
The JPG mover skips files when a file with the same name already exists in the destination.
